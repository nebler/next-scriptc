## Local patch defect and fix

Commit `2a3ce4ba62cac4932873b6df9d95b2a553c02f20` fixes a genuine complexity regression introduced by `d49007483`. `wrappingRange` first ran the strict recursive proof over an arithmetic subtree, then repeated that proof while recursively visiting its children. One query over an unproven sum chain required quadratic fact lookups: 528, 2,080, 8,256, and 32,896 for lengths 32, 64, 128, and 256. Upstream required 32, 64, 128, and 256.

The fix handles arithmetic subtrees in one traversal, reuses stored facts, and delegates leaves to the strict proof. It preserves the signed-zero-tolerant wrapping rules. A deterministic test bounds fact queries instead of using a timing threshold. The valid typed test fails before the fix with 33,153 lookups against a 1,024 budget, then passes after the fix. The probe returns to upstream's linear counts. This establishes the traversal defect independently of the OOM investigation; OOM causality is not established.
