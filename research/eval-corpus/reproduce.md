# Reproduce the corpus

Use a disposable directory under `/tmp`. The application revisions are in `manifest.json`. All application source, transpiled modules, dependencies, and native objects must remain outside the repository.

Install the tools with `npm install --prefix /tmp/nsc-eval-tools --ignore-scripts --no-audit --no-fund typescript@5.9.3 @babel/parser@7 @babel/traverse@7 @babel/generator@7 @babel/types@7 tsx scriptc@0.4.6`. Exact installed versions are in `tool-versions.json`. Temporarily link this worktree's `packages/scriptc-promote/node_modules` to that temporary tool directory. Do not replace an existing dependency directory. No link may point into the main checkout. The compiler package's postinstall normally sets executable permissions. With scripts disabled, grant execute permission to its Mach-O executables and launcher files inside `/tmp` yourself. Never execute an application lifecycle script.

For each manifest repository, shallow-clone its URL, fetch the recorded revision if necessary, and check that `git rev-parse HEAD` matches the manifest. Keep at most three source trees at a time. `python3 research/eval-corpus/inspect.py /tmp/clone DOMAIN FRAMEWORK /tmp/inspection.json` inventories metadata without executing app code. Search scores count numeric syntax and loops; they deliberately do not assert a hot path. Vendored browser bundles and seed scripts can score highly.

Make TypeScript available to the checkout via its temporary `node_modules`. Run `node research/eval-corpus/census.mjs /tmp/clone SOURCE_SCOPE ... > /tmp/census.json` with the exact scopes recorded in each primary census. Primary scans used a 45-second deadline and a 2 GiB Node heap, except the initial Umami and Rybbit scans which had a 150-second deadline. Whole-scope failures remain failures. Additional narrow scans cover Actual's budget source, GrowthBook stats-ts, and Rybbit experiment statistics. The recorded narrowed Actual and Rybbit scans use only the target module, with Git revision metadata retained; they do not resolve the complete application graph. No app dependencies were installed. Do not interpret missing imports as compiler incompatibility with a fully installed app.

For timing, arrange the four benchmark source modules under `/tmp/checkouts/{rybbit,growthbook,actual,umami}` at their original relative paths. `cases.json` selects symbols and deterministic arguments. The harness transpiles an unchanged full module or extracts an unchanged dependency closure using the existing extractor. Private helpers are exposed for measurement. Extraction does not imply promotion acceptance. No compiler or adapter optimization is applied.

Build the accepted Umami controls with `SCRIPTC_COMPILER=/tmp/nsc-eval-tools/node_modules/@scriptc/cli-darwin-arm64/dist/bin/scriptc node research/eval-corpus/native-screen.mjs /tmp/checkouts/umami src/lib /tmp/nsc-eval-native research/eval-corpus/native-build.json`. This uses stock scriptc 0.4.6, the installed host runtime, and cached Node 24.22.1 N-API headers. All three controls compile. The native build report retains two initial executable-permission failures from the `--ignore-scripts` install.

Stop task scans and builds before timing. Copy our bench.mjs to /tmp and run `EVAL_REPO_ROOT=/path/to/this/worktree node /tmp/bench.mjs /tmp/checkouts /path/to/cases.json /tmp/intensity.json /tmp/nsc-eval-native`. The final recorded run uses this external execution path. Omit the native directory for JS-only results. CPU samples for tiny calls are quantized by the process CPU clock; elapsed ratios are descriptive and do not pass the protocol's CPU confidence gate. Warm caches, JIT behavior, host background work, and a single session limit inference. Inputs are synthetic, with no production traffic frequencies.

Remove all temporary clones, dependencies, compiled outputs, and task-created dependency links afterward. Preserve compressed result JSON using deterministic Node gzip with level 9 and MTIME zero, as in `scripts/compress-artifacts.mjs`. No uncompressed artifact may exceed 256 KiB. The corpus includes no third-party source.
