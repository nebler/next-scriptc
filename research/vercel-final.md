## Method, review and provenance

This is the prototype next-scriptc Next.js adapter, without a Next.js fork. The same `app/**/route.native.ts` handlers, algorithms, request fixtures and lockfile run as ordinary optimized Next.js App Routes on Node and as scriptc release-mode executable Functions. The six registered workloads are hello (transport control), HS256 verify, revenue aggregation, 5,000-row gzip export, 20,000-store search and full Markdown rendering. No workload was selected or removed after this run began.

Review of the two inherited commits (`935d3b3`, `4ccfccb`) retained the method and found harness defects: cold-only warm failures were not propagated; full-run correctness failures could be followed by more workload measurements; accepted preview identity could be lost on inspection failure; native binaries were not tied to the Linux-validated hash; resource/shared-Function checks and missing-artifact budget accounting were incomplete. Commit `10d23f6` fixed these before any final preview. The dated [pre-measurement amendment](benchmarks.md#final-run-review-amendment--2026-10-31-before-any-final-previews-or-hosted-requests) records the changes. No adapter, shim or measured-handler behavior changed.

One unmeasured pair-2 native upload failed with `fetch failed`. A control-plane listing showed no accepted preview from it. The original failure/provenance/cost snapshot is retained in [control-failure](benchmarks/vercel-final-control-failure.json); the one-off [archived recovery controller](../examples/demo/bench/vercel/archive/final-recover.mjs) then executed only the missing frozen stages from the same source commit. Pair 1 was neither repeated nor replaced. This used the prospectively allowed deployment-failure recovery; workload windows and acceptance rules did not change.

After all twelve full-pair workload rows and both post-load memory probes completed and were downloaded, the SDK stop call exceeded its 20-second deadline. The raw [pair-5](benchmarks/vercel-final-pair-5.json) remains **status failed**, with its original `stopError`.
