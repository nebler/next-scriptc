# Four directions

Each direction is a complete system applied to every launch graphic. They differ in composition and in how the number is presented, not only in color. Every chart keeps one takeaway, a plain-language headline, a zero-based scale and one short caveat line. Full methods live in the gallery.

## A · Monolith

The number is the image. One large figure carries the takeaway, a single sentence explains it and thin direct-labelled bars confirm it underneath. No axes, legends or frames; a single zero line anchors the bars. Black, white and one gray: the native result is the only white mark. Space is the main material. Code images drop all chrome and show only the file name and the code, or dim everything except the one line that matters.

## B · Editorial

A printed financial-page chart. Warm paper, a heavy rule across the top, a serif headline written as a sentence that states the finding, then a ranked horizontal bar chart with row labels on the left, values at the bar ends and quiet ticks. Native is the only saturated color (ink blue); everything else is warm gray. Code is set like a figure in a book, with a margin note in italic.

## C · Spec sheet

The lineage of the current assets, decluttered. A precise frame with crosshair registration marks splits the canvas: plain text on the left (headline, one sentence, a mono method label), one clean column chart on the right. Native white, comparisons Vercel blue, Geist Mono for technical labels. Code sits inside the frame with line numbers and a file tab.

## D · Signal

A saturated blue field and counted units. Instead of bars, quantities are drawn as tallies of small squares (each square is one stated unit, so the scale starts at zero by construction and partial squares are drawn exactly). It reads as "native is a handful of squares, Node is a wall of them". White type, very little of it. Code floats on the field as a dark card.
